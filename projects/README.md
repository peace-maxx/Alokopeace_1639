# Project index

This repository includes three separate Flutter projects. The purpose of this folder is to document and organize those projects clearly.

## Projects

- [farm_app](./farm_app/README.md) — the active project kept at the repository root
- [screen_1](./screen_1/README.md) — the Screen_1 prototype project
- [flutter_application_1](./flutter_application_1/README.md) — the initial Flutter app project

## Organization rule

The root repository is treated as the main `farm_app` app. The two other app folders remain separate and should not be merged into the root app code unless intentionally required.
